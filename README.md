# Arla Norway demo assets

Video and still for the welcome page of a Power BI prototype built by Optia Data. Nothing else lives here: no data,
no code.

- `Arla_Norway_Welcome_Loop.mp4`: 19 s muted loop, 1280x720.
- `Arla_Norway_Welcome_Still.jpg`: poster frame.
- `PROVENANCE.md`: source, author, licence and edits for every clip.

The footage is licensed stock from Pixabay (Pixabay Content License) and may include computer-generated imagery.
The prototype it belongs to runs on synthetic data only: not NielsenIQ or Arla data. This is not an official Arla
product and is not endorsed by Arla.
